機種選びの進め方

仮整理から、正式な選定へ。

基本の3条件で候補を絞り、詳しい条件と実際の運用を順番に確認します。

01 / INPUT

材料条件を
そろえる

材質、形状、材料断面、素材全長、切断長を確認。分からない項目は、材料写真から一緒に整理できます。

02 / REQUIREMENT

切り方と必要量を
整理する

必要本数、公差、束ね切り、角度切り、使用環境を確認し、必要な能力と自動化の範囲を整理します。

03 / SELECT

導入後まで含めて
候補を比べる

条件に合う候補を仕様と実切断で確認。投入・送り・切断・搬出・仕分け、設置や保守まで比べます。

実切断で見る選定ポイント

「切れた」だけでなく、
3つを見ます。

候補機は、カタログの最大能力だけでは決めません。材料条件と照らし合わせ、実機で「保持」「刃まわり」「切断面」を確認します。

  • 材料を安定して保持できるか丸材や束材が機械に収まり、安定して固定できるかを見ます。
  • 刃とガイドを材料に合わせられるか材料の形状に合わせ、刃・ガイドの位置を確認します。
  • 切断後の状態が用途に合うか切断面と材料の状態を見て、求める仕上がりとの違いを確認します。

この3点を、材質・断面寸法・切断長・必要本数と合わせて候補選びの参考にします。実切断テストの可否は、材料・機種・時期を確認してご案内します。

Frequently asked

よくある
ご相談。

相談時には何を伝えればよいですか？

まず、機械選定・切断改善・修理のどれかをお知らせください。選定は材料・切断・生産条件、改善は現在の機械・刃・困りごと、修理は機種・製造番号・症状を伺います。分かる範囲で大丈夫です。

機種が決まっていなくても相談できますか？

はい。材質、形状、寸法、数量、設置環境などから候補を整理します。現在使っている機械の情報もあわせてお知らせください。

実切断やテストについて相談できますか？

対応可否や条件は材料・機種によって異なります。まず材料と切断条件をお知らせください。

価格や納期を確認できますか？

機種、仕様、周辺設備、時期によって異なるため、ご相談時に最新の価格・納期をご案内します。

導入後の修理やメンテナンスも相談できますか？

はい。ラスターマシナリーでは、工作機械の出張修理・保守メンテナンスにも対応しています。症状が分かる写真・動画・銘板をご用意ください。
